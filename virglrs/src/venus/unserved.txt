# The venus commands this build does not serve.
#
# The capset's extension mask is built from what the pinned vk.xml can *serialize*, which is every
# command below as well as the ones we serve. So a guest may legally send any of these, and each
# one poisons its context. That is the right answer -- a zeroed reply is shaped exactly like a
# successful one, so there is no safe way to continue -- but it is only the right answer while the
# set is a decision rather than an accident.
#
# This file is that decision. `every_command_the_protocol_defines_is_served_or_on_the_ledger`
# holds the two sets to it: serving a command means deleting its line, and a protocol bump that
# adds one means adding a line. Three boots found three of these one at a time before the set was
# written down; nothing here is a promise to serve them, only a record that we know.
